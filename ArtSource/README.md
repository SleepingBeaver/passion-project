# Fontes de arte

Esta pasta guarda os arquivos editáveis e exportações originais recebidos para o projeto. Ela fica fora de `Assets` para o Unity não importar fontes de trabalho desnecessariamente.

- Edite `.aseprite` aqui.
- Exporte sprites finais para o diretório apropriado em `Assets/Art`.
- Preserve nomes e slices já referenciados por cenas/prefabs ou faça a migração no Editor.
- Use Point Filter, sem mipmaps, sem compressão e 64 PPU para pixel art do jogo.
